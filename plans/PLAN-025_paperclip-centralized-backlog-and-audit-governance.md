## 1. Executive Summary & Target Single-Authority Topology

Multi-agent SDLC flows require centralized cross-repo task coordination, atomic checkout locking, hard LLM cost ceilings, separation-of-duties (`SoD`) human gates, and non-duplicative audit tracking. Currently, ecosystem governance splits backlog intent across GitHub Issues (`submit-feedback/SKILL.md`), `platform-paperclip` (`v0.4.2`), and undocumented ad-hoc Markdown audits, while `platform-paperclip` `v0.4.2` itself lacks DB-sequence IDs, editable task metadata, comments, SQL filtering/pagination, PgBouncer transaction-safe locking, strict `[I-10]` nonces, and verified Bearer/ForwardAuth enforcement.

This master plan establishes a single-authority topology across four coordinated repositories (`platform-paperclip`, `platform-stage-ops`, `aiops-harness`, and `aidoc-flow-engramory`):

| Surface | Canonical Role | What Lives There & Authoritative Controls |
| :--- | :--- | :--- |
| **Git (`docs/audits/AUDIT-YYYY-MM-DD_<slug>.md`)** | **Immutable Audit Report Store** | Source-verified audit prose (`DOC-FM-000` frontmatter `kind: audit`, `status: active \| archived`, `Audit-Status: open \| dispositioned \| closed`), plus wave-split `## Disposition ledger` verified offline by `audit-disposition`. |
| **`platform-paperclip` `v0.5.0` (`paperclip.issues` + `paperclip.comments`)** | **Single Centralized Internal Backlog & Agent Control Plane** | All internal TODOs, queued backlog items (`state="Backlog"`), dispatchable tasks (`ReadyForDev`), cross-repo audit task trees (`parent_task_id`, DAG `depends_on`), priorities (`P0..P3`), `Origin: real-use \| review`, Rule D14 `audit_report` pointers, threaded comments, transactional Postgres `FOR UPDATE` leases, spend kill-switches, and human-only SoD approvals. |
| **`platform-gitea` (`1.27.3-rootless`)** | **Git Repository, PR Review & Dev CI Forge Only** | Code hosting (`dev`), feature branches, PR diffs/reviews, Gitea Actions CI. Gitea Issues are **not** used as an agentic backlog; PRs auto-link via mesh HMAC-verified Gitea webhook (`Refs: pc-task-*` / `Closes: pc-task-*`). |
| **Chatwoot (`aiops-agent-support`) + GitHub Issues** | **External & Public OSS Intake** | Customer support omnichannel & public OSS repo issues (`ADR-0004`). Internal findings go directly to Paperclip (or Chatwoot $\to$ Paperclip linked via `chatwoot_conversation_id` / `source_ref`), with strictly **one Status Authority** per item. |
